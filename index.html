Chapter 1: Make It Yours

Six challenges. No experience needed.

1. Colours 2. Size 3. Speed 4. Catcher 5. Lives 6. Your game
Challenge 1 of 6

🎨 Give the game a new look

Find the colour variables near the top of your Python code.

BACKGROUND = (20, 25, 50)
YELLOW = (255, 220, 50)

Colours use three numbers: red, green, and blue. Each number ranges from 0 to 255.

Your task: change the background and star colours. Can you make a purple space game?

Need a hint?

Try BACKGROUND = (70, 20, 100). Change one number at a time to see what it does.

Challenge yourself

Create an underwater theme using blue and green shades. Give your game a matching star colour.

Challenge 2 of 6

🔵 Make the star bigger

Find where the star is created:

star = pygame.Rect(
    random.randint(0, WIDTH - 20), 0, 20, 20
)

The last two numbers are its width and height.

Your task: change both 20s to 40. Run the game. Is the star easier to catch?

Need a hint?

Try random.randint(0, WIDTH - 40) as well, so the larger star stays within the screen.

Challenge yourself

Make a very wide, short star. What happens if the width and height are different?

Challenge 3 of 6

⚡ Speed things up

Find these variables:

player_speed = 8
star_speed = 3

These numbers control how far the player and star move each frame.

Your task: make the player faster and then make the star slower.

Need a hint?

Try player_speed = 12 and star_speed = 2.

Challenge yourself

Can you make a game that's almost impossible to win? Now make it easy enough for a beginner.

Challenge 4 of 6

🟩 Build a giant catcher

Find the line that creates the green player:

player = pygame.Rect(270, 350, 60, 20)

The numbers set its starting x-position, y-position, width, and height.

Your task: make the catcher wider or taller.

Need a hint?

Try changing the width from 60 to 120.

Challenge yourself

Make the catcher start on the left side of the screen. Can you work out which number controls that?

Challenge 5 of 6

❤️ Change the rules

Find the game-over condition:

if misses >= 3:

This means the game ends when misses reaches three.

Your task: change the number to 5. Now you have five misses before game over.

Need a hint?

You only need to change the number in this condition. Keep the colon at the end.

Challenge yourself

Try just one life, then ten. Which version is more fun?

Challenge 6 of 6

🚀 Create your own game

Now it's your turn to be the designer.

Your task: make at least three changes from the earlier challenges. Give your game a name and tell someone what you changed.

Need inspiration?

Try a new colour theme, a giant catcher, faster stars, and five lives. Or invent your own combination.

Before you finish

Can you explain which variables you changed and what each one does? Being able to explain your code is part of being a programmer.

🎉 Chapter complete!

You've changed the appearance, size, speed, and rules of a Python game. That's real programming.

Save your own copy of the code so you can keep experimenting.
