What is a condition?

Imagine someone says: "If it's raining, take an umbrella." That's a decision. Python can make decisions in exactly the same way.

if it_is_raining:
    take_an_umbrella()

Python checks whether a condition is true. If it is, it runs the indented code underneath it.

In our game, we already use conditions to check whether a star touches the player.

Challenge 2 of 6

✅ Make a decision using a number

Python can compare numbers. For example:

score = 10

if score >= 10:
    print("You are doing great!")

The symbol >= means "greater than or equal to". The message appears because the score is 10.

Your task: change the score to 5. Then change the condition to score >= 5. Try other numbers.

Need a hint?

Try changing one number at a time. Ask yourself whether the condition should be true or false.

Challenge yourself

Challenge 3 of 6

🔀 Meet else

What if you want the game to do something when a condition is false? Use else.

score = 4

if score >= 10:
    print("You win!")
else:
    print("Keep trying!")

Only one of these messages appears. If the score is at least 10, Python prints "You win!". Otherwise, it prints "Keep trying!".

Your task: try scores of 4 and 12. Observe which message appears each time.

Need a hint?

else doesn't need its own condition. It runs when the if condition is false.

Challenge yourself

Write your own two messages: one for a score of 10 or more, and another for a score below 10.

Challenge 5 of 6

🌈 Add more than two choices with elif

Sometimes a game needs more than two outcomes. Python has elif, which means "else if".

score = 12

if score >= 20:
    print("Gold level!")
elif score >= 10:
    print("Silver level!")
else:
    print("Bronze level!")

Python checks the conditions from top to bottom and runs the first matching branch. If none match, it runs else.

Your task: try scores of 5, 12 and 25. What level does each score earn?

Need a hint?

For a score of 12, the first condition is false, but the second is true. Python prints "Silver level!".

Challenge yourself

Add a new level called "Platinum level!" for scores of 50 or more. Put its condition before the Gold condition.

Challenge 6 of 6

🚀 Make your game react to the score

Now combine what you've learned. In your game, find the code that runs when the player catches a star:

if player.colliderect(star):
    score += 1

You could use an if condition to make something happen when the score reaches a target.

if score >= 10:
    print("Amazing! Ten stars!")

Your task: experiment with a score condition. Start by changing the target from 10 to 3.

Need a hint?

In your actual game, the score condition needs to be inside the main game loop if you want it checked continuously. Be careful: a message printed every frame can appear many times.

Challenge yourself

🎉 Chapter complete!

You have learned how to use if, else, elif, and comparison operators to make decisions in Python.

These are some of the building blocks of almost every game and program.

Remember: indentation matters in Python. The lines belonging to an if, elif, or else block must be indented consistently.
